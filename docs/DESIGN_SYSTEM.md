# Design System — Y2K Pixel Desktop

TREND RADAR는 Y2K 레트로 데스크톱 감성을 씁니다. 하늘·구름·픽셀 잔디 배경과 픽셀 격자 질감 위에 **평면 레트로 OS 창**을 올립니다. 창은 검은 외곽선, 파란 타이틀바, 네모 `_ □ ×` 버튼을 갖습니다. 포인트는 **스티커형 그림자**, **노란 형광펜 섹션 바**, **형광 초록 주 버튼**, **검은 알약 선택 칩**입니다. 토큰은 모두 `app/globals.css`의 `:root`에 있습니다.

배경 일러스트(`public/sky-pixel.svg`)는 직접 그린 SVG입니다. 레퍼런스에 나온 브랜드·아이돌·서비스의 로고, 이름, 캐릭터, 사진은 쓰지 않습니다.

> 변경 이력: Windows 3.1 → Retro OS × Frutiger Aero → Y2K Messenger Meadow → **Y2K Pixel Desktop**(2026-10-29). 레이아웃·컴포넌트 구조는 그대로이고 색·외곽선·그림자·제목 글꼴만 바뀌었습니다.

## 가독성 원칙

- 본문은 **Pretendard 14px**(줄간격 1.6)입니다. 픽셀 글꼴 **Galmuri11**은 큰 제목, 창 제목, 메뉴 그룹 제목, 섹션 번호, 폼 라벨에만 씁니다. 본문과 작은 설명에는 쓰지 않습니다.
- 보조 텍스트는 최소 **11px**입니다.
- 창과 패널 바탕은 **불투명한 흰색**입니다. 하늘이나 잔디 위에 글자를 바로 놓지 않습니다(`.provenance`, `.section-heading p`, `.map-legend`는 흰 바탕).
- 형광 노랑·초록 위에는 항상 **검은 글자**를 씁니다. 흰 글자는 파란 타이틀바, 검은 알약 위에서만 씁니다.
- 픽셀 격자 질감은 배경에만 깔고 창 안에는 깔지 않습니다.

## Tokens

| 토큰 | 값 | 용도 |
|---|---|---|
| 배경(`body::before`) | `public/sky-pixel.svg` (하늘 `#3f7cf2 → #f4f8ff`, 부드러운 구름, 계단식 픽셀 잔디, 가장자리 픽셀 하트·반짝이) | 고정 배경 |
| 배경(`body::after`) | 8px 흰 격자 13% | 픽셀 모자이크 질감 |
| `--ink` | `#14161f` | 외곽선, 그림자, 검은 알약, 본문 글자 |
| `--surface` | `#ffffff` | 창·패널 |
| `--win-frame` | 검은 2px 외곽선 + `5px 5px 0` 그림자 | 타이틀바가 있는 창, 사이드바 |
| `--drop` / `--hard` | `4px 4px 0` / `3px 3px 0` 검은 그림자 | 패널 / 버튼·섹션 바 |
| `--title-grad` | `#3a50ff → #2238e6` | 타이틀바, 모바일 상단 바 |
| `--bar-grad` | 형광 노랑 `#f6ff3a` | 섹션 헤더 바, 메뉴 그룹 헤더, 형광펜 밑줄 |
| `--lime-grad` / `--cream-grad` | 형광 초록 `#5cf28c` | 주 버튼, 활성 메뉴, LIVE 배지, 로고 칩 |
| `--form-grad` | `#f1fff5 → #dcfbe6` | 민트 입력 영역(브랜드 카드) |
| `--title` / `--blue` | `#1f2fe0` | 강조 제목, 링크, 근거 ID, 아이콘 |
| `--neon-pink` | `#ff4fa3` | 포커스 링 |
| `--pink` / `--yellow` | `#e5266d` / `#c98a00` | 하락·오류 / 경고·DEMO |
| `--text` / `--muted` | `#14161f` / `#555a6b` | 본문 / 보조 |

의미 색은 유지합니다. 저장된 분석(SAVED/CACHED)은 하늘색, DEMO는 주황 사선 줄무늬, 오류는 빨강입니다. Culture Map 관계 유형 선 색(관찰 초록, 공통 속성 파랑, 의미 유사 파란 점선, AI 가설 주황 점선)은 구분이 목적이라 그대로 둡니다.

## Components

| 요소 | 규칙 |
|---|---|
| 창 크롬 | `.panel:has(>.titlebar)`·`.window`: 검은 2px 외곽선 + 스티커 그림자, 반경 6px. 타이틀바는 파란색 + 흰 Galmuri 12px |
| 창 버튼 | `WinButtons`: 흰 네모 `_ □ ×` + 검은 외곽선. 장식이며 동작은 없습니다 |
| 사이드바 | 흰 창. 메뉴 그룹 헤더는 노랑, 활성 항목은 형광 초록 + 위아래 검은 선 |
| 버튼 | 흰 바탕 + 검은 1.5px 외곽선 + `3px` 그림자. hover 때 1px 떠오르고, 누르면 그림자만큼 들어갑니다. 주 버튼은 형광 초록 |
| 칩 | 기본은 흰 알약, 선택되면 검은 알약에 흰 글자 |
| 입력창 | 흰 사각(반경 6px) + 검은 1.5px 외곽선. 포커스는 파란 외곽선과 링 |
| 섹션 제목 | 노란 형광펜 바 + 검은 외곽선·그림자 + Galmuri 제목, 번호는 검은 알약 |
| 페이지 제목 | Galmuri 굵게. 강조 줄은 파란 글자 + 노란 형광펜 밑줄 |
| 진행률 | 검은 테두리 안의 파란 칸 블록 |
| 스크롤바 | 파란 사각 손잡이 + 검은 외곽선 |
| React Flow | 컨트롤·미니맵은 검은 외곽선, 노드는 흰 카드 |

## Do / Don't

- Do: 형광색 위에는 검은 글자를 씁니다.
- Do: DEMO 데이터는 주황 사선 줄무늬로 구분합니다.
- Don't: 픽셀 글꼴을 본문, 표, 긴 설명에 쓰지 않습니다.
- Don't: 실제 브랜드·연예인·서비스의 로고, 이름, 캐릭터, 사진을 가져오지 않습니다.
- Don't: 배경 위에 바탕 없이 글자를 올리지 않습니다.
