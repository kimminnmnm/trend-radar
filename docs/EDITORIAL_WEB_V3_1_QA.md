## 확인한 것
**데이터 정확성**
- 노드 수 = 저장된 분석 수
- 관계선 수 = 관계 엔진 결과 수
  - 관계가 없으면 선이 0개이고 범례에 그렇다고 표시한다.
  - DNA가 있는 두 트렌드는 Collision 없이도 엔진이 "공통 속성"을 찾는다. 처음 테스트 가정이 틀렸던 것을 바로잡았다.
- 파형 측정점 수 = 저장 시계열 길이. 시계열이 없으면 파형을 그리지 않는다.
- Pulse
  - 처음 측정한 태그는 NEW로 표시하고 막대는 없다.
  - 툴팁의 값은 저장값이다.
- HIGH SCORE
  - "실제 검색량 아님"을 표시한다.
  - 다른 요청 묶음의 키워드를 섞으면 "추정치" 문구가 나온다.

**그 밖**
- 키보드: 노드에 포커스하고 Enter로 선택한다. Pulse 행은 포커스로 툴팁이 열린다.
- Classic: 막대·툴팁·차트가 없고, Pulse 행 수가 같다.
- 동작 줄이기: 히어로·파형 애니메이션이 `none`이다.
- 유료 API: 0건.
