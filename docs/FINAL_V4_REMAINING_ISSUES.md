## C. 운영상 한계
- 비용 상한(분당·일일)과 결과 캐시는 서버 메모리 기준이다. 서버를 다시 켜면 초기화되고, 여러 서버에 나눠 배포하면 서버마다 따로 센다.
- 오래 켜 둔 개발 서버가 예전 모듈로 응답한 일이 두 번 있었다(실사용). 코드를 바꾼 뒤에는 서버를 다시 켜야 한다.
- 접근성은 기본 검사(버튼·링크 이름, 이미지 대체 텍스트, 입력 라벨, 문서 언어, 제목)만 했다. 색 대비·키보드 순서·스크린리더 실사용은 확인하지 않았다.
