# TREND RADAR — INTERACTIVE VISUALIZATION SPEC (Editorial Web V3.1)

이 문서의 모든 시각화가 지키는 규칙: **저장된 실제 데이터만 쓴다.** 없는 관계선, 시계열, 상승률, 인기 지수를 만들지 않는다. 화면을 여는 것만으로 API를 호출하지 않는다.

## 1. Hero · SIGNAL VISUALIZER (`components/signal-visualizer.tsx`)
| 항목 | 내용 |
|---|---|
| 변경 전 | 검은 목록(트렌드 이름 · WHY/DNA 표시)과 숫자 4개. 관계와 흐름을 볼 수 없음 |
| 설계 의도 | 내가 분석한 트렌드가 서로 어떻게 이어지는지(A), 선택한 트렌드의 관심도가 어떻게 움직였는지(B), 지금 무엇을 할 수 있는지(C)를 한 영역에서 |
| 노드 | 저장된 LIVE 분석 최근 8개. **크기 = 근거 항목 수**(√ 비례), **라임 = DNA 완료**, 흰색 = WHY만 |
| 배치 | 2개는 좌우, 3개 이상은 타원 둘레. 위치 자체에는 의미가 없다(범례에 명시) |
| 관계선 | `buildCultureGraph(...).relations`(Culture Map과 같은 관계 엔진)만. 선 종류는 관계 유형별: 관찰된 연결(검정 실선) · 공통 속성(파랑 실선) · 의미 유사(파랑 점선) · 창작 가설(보라 파선) |
| 관계가 없을 때 | 선을 그리지 않고 범례에 "근거 있는 관계 없음 — 선을 그리지 않음" |
| B. SIGNAL WAVE | 선택한 트렌드에 저장된 `naverSignal.series`(그 트렌드 이름의 시계열) 그대로. "NAVER 상대 관심도 · 실제 검색량 아님 · 그 분석 요청 안 최댓값 = 100". 다른 트렌드와 높이를 비교하지 않음(요청마다 기준이 다름). 시계열이 없으면 "저장된 NAVER 시계열이 없어 파형을 그리지 않습니다" |
| C. TREND SNAPSHOT | 이름 · 마지막 분석 시각 · 근거 수 · DNA 여부 · 관련 현상(같은 키워드의 WHAT'S HAPPENING NOW? 결과 최대 3개 + 관측 상태) · WHY / DNA / CREATE |
| 인터랙션 | hover·focus: 노드 확대 + 연결된 노드·선 강조, 나머지 흐림. click·Enter·Space: 선택(다시 누르면 해제). 전체 보기: 선택 해제. 파형 위 hover: 그 주의 값. 노드와 같은 선택을 아래 이름 버튼으로도 제공(키보드·모바일) |
| 드래그 | 넣지 않음. 노드가 8개 이하이고 겹치지 않게 배치되어 필요 없음 |
| 데이터가 없을 때 | "아직 분석한 트렌드가 없어 그릴 신호가 없습니다" + 첫 키워드 분석. **예시 네트워크를 그리지 않음** |
| 성능 | SVG(노드 8개 이하, 선은 관계 수만큼). 캔버스·WebGL·새 라이브러리 없음. 관계 계산은 `useMemo` |
| 테스트 | `tests/editorial-v31.spec.ts` Hero 3건: 노드 수 = 분석 수, 선 수 = 관계 수, 파형 측정점 수 = 저장 시계열 길이, 관계·시계열이 없을 때 그리지 않음, 빈 상태, 키보드 선택 |

## 2. Instagram Pulse 막대·툴팁 (`components/ig-pulse.tsx`, Editorial일 때만)
| 항목 | 내용 |
|---|---|
| 변경 전 | 숫자만 있는 순위 목록. 값의 상대 크기와 이전 측정을 한눈에 볼 수 없음 |
| 많이 올라오는 순 | 행 아래 4px 막대. **길이 = 이 차트 안 최댓값 대비 게시 속도(perHour)**. 최소 2% |
| 오르는 순 | 비교 가능한 이전 측정이 있는 행만 막대(길이 = 이 목록 안 최대 |변화율| 대비, 초록 상승 · 빨강 하락). **NEW 행은 막대 없음** |
| 툴팁 | 해시태그 · 게시 속도(24시간 평균 / 최근 N시간 표본) · 최근 24시간 게시물(끝까지 셌으면 정확값, 아니면 "N개 이상") · 이전 측정(값·시각 / "없음(처음 측정)" / "20시간 이내라 비교 대기") · 변화율(+/−% / "NEW · 계산하지 않음" / "이전 0 → 증가(비율 없음)") · 마지막 측정 · 데이터 상태(LIVE / CACHED / SAVED / 이전 측정 결과) |
| 인터랙션 | hover 또는 키보드 포커스(행이 Tab으로 이동 가능)로 툴팁. RESCAN 직후 이번 측정 행을 한 번 라임으로 강조. 측정값이 바뀌면 막대 길이 전환 |
| 하지 않은 것 | 순위 자리바꿈 애니메이션(FLIP)은 넣지 않음. 막대 길이 전환과 갱신 강조로 대신함 |
| Classic | 막대·툴팁·포커스 없음(마크업이 이전과 같음). 테스트로 확인 |

## 4. Hero 타이포그래피
- 문구는 그대로다: READ THE SIGNAL. / UNDERSTAND THE CULTURE.
- 4줄 비대칭 배치
  - SIGNAL.: 라임 블록
  - UNDERSTAND: 파랑, 들여쓰기
  - THE CULTURE.: 들여쓰기
- 글자 크기는 제목 영역 폭 기준(`cqi`)이고, 줄 안에서 끊기지 않는다(`nowrap`). 지원하지 않는 브라우저는 화면 폭(`vw`) 기준을 쓴다.
- 접근성: 화면 읽기 도구는 h1을 "READ THE SIGNAL. UNDERSTAND THE CULTURE."로 읽는다(테스트로 확인).
- 분석이 있으면 제목 아래에 숫자 4개를 둔다: 분석, 근거, 근거 있는 연결, 아이디어. 모두 저장 데이터로 센다.
