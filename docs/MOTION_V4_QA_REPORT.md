## 3. 성능
- 새 라이브러리는 없다. `framer-motion`은 의존성에 있지만 쓰지 않는다.
- 움직이는 속성: transform · opacity · clip-path · stroke-dashoffset. 화면 밖에서는 반복 움직임을 멈추고, 모바일에서는 반복 움직임이 없다.
- 차트는 보일 때 그린다.
- **측정하지 않음:** 프레임 수(FPS), 저사양 기기 끊김, 배터리, 번들 크기 수치.
