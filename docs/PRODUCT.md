# Product Definition

## Problem

일반적인 트렌드 도구는 검색량이나 인기 콘텐츠를 보여주지만, 실무자는 다시 여러 자료를 오가며 “왜 지금 주목받는가”, “어떤 욕구가 연결되는가”, “브랜드가 무엇을 할 수 있는가”를 해석해야 합니다. 생성형 AI만 사용하면 출처 없는 설명과 그럴듯한 인과관계가 섞일 위험이 있습니다.

TREND RADAR는 관찰 사실, 근거 있는 해석, 창의적 가설을 분리한 뒤 Discover → Why → DNA → Collision → Lab → Studio라는 하나의 맥락으로 연결합니다.

## Primary user

문화·콘텐츠·브랜드 전략을 만드는 주니어 전략가, 콘텐츠 마케터, 디자이너. 빠르게 아이디어를 얻되 출처와 불확실성을 확인할 필요가 있는 사람입니다.

## Before / After journey

| 기존 방식 | TREND RADAR |
|---|---|
| 여러 플랫폼에서 유행 키워드 수집 | Discover에서 탐색 대상을 선택 |
| 기사와 SNS를 수작업으로 정리 | Why에서 시간·근거·가설을 연결 |
| 직관으로 유사 트렌드를 조합 | DNA와 Culture Map으로 공유 속성 탐색 |
| 곧바로 콘텐츠 생성 | Lab에서 수요·적합성·실행성을 먼저 검토 |
| 결과물에 근거가 남지 않음 | Studio 기획안에 활용한 분석과 검증 항목 표시 |

## Competitive position

검색량 중심 도구와 달리 ‘문화적 이유’를, 소셜 리스닝 도구와 달리 ‘문화 간 연결’을, 범용 AI 챗봇과 달리 ‘증거 상태와 구조화된 흐름’을 제품의 중심에 둡니다. 경쟁 우위는 더 많은 숫자가 아니라 해석 과정의 가시성과 기획으로의 연결입니다.

## Success criteria

실제 사용자 검증 전에는 성과를 주장하지 않습니다. MVP 검증 지표 후보는 첫 인사이트 도달 시간, 근거 상세 열람률, Collision에서 Lab으로 이동률, 완성된 콘텐츠 기획안 비율, 사용자 신뢰도 인터뷰 점수입니다.
