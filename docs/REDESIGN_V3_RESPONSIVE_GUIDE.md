## 가로 스크롤 규칙
- 페이지 전체에는 가로 스크롤이 생기지 않아야 한다.
  - 자동 테스트: `tests/redesign-v3.spec.ts`에서 9개 화면을 데스크톱·모바일(Pixel 5) 두 크기로 확인한다.
  - 개발 중 375px에서 따로 확인: Discover와 Workspace가 6–10px 넘쳐서 고쳤다.
- 진행 막대의 단계 목록은 **그 영역 안에서만** 가로로 스크롤된다(기존 동작).
- **넘침 원인과 수정**
  - 원인: `1fr` 그리드의 카드가 굵은 버튼과 자간 넓은 배지 때문에 내용 최소 폭만큼 커졌다.
  - 수정: Editorial에서 그리드 항목을 `min-width:0`으로, 배지는 줄바꿈 허용.

## 터치·모션
- 모바일 메뉴 항목은 높이 44–48px이다. 상단 버튼은 40×44px이다.
- `prefers-reduced-motion`이면 hover 이동과 애니메이션을 끈다.
