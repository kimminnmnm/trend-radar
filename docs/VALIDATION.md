# Validation Plan

아직 사용자 조사나 성과 측정을 수행하지 않았습니다. 아래는 MVP 출시 후 실행할 계획입니다.

## Participants

콘텐츠 마케터 3명, 브랜드/문화 리서처 3명, 디자인·마케팅 취업 준비생 2명. 특정 산업에 치우치지 않도록 경력과 업무 맥락을 섞습니다.

## Tasks

1. 낯선 트렌드를 발견하고 왜 주목할 가치가 있는지 설명하기.
2. WHY에서 사실과 가설을 구분하고 신뢰 가능한 근거 찾기.
3. DNA/Map에서 두 문화를 선택하고 연결 이유를 말하기.
4. 자신의 브랜드로 Lab 검토 후 Studio 기획안 만들기.
5. 결과물을 저장하고 다시 찾기.

## Measures

- 첫 의미 있는 인사이트까지 걸린 시간
- 검증 상태를 정확히 이해한 참가자 비율
- 근거와 해석을 혼동한 횟수
- 단계별 이탈 및 되돌아가기
- “기획에 새 관점을 주었는가” 7점 척도와 인터뷰 근거

## Key questions

그래프가 이해를 돕는가, 장식처럼 보이는가? Creative Hypothesis가 안전장치로 인지되는가? 단계가 유용한 사고 흐름인가, 강제된 퍼널인가? 결과를 실제 업무 문서로 옮길 때 빠진 필드는 무엇인가?
