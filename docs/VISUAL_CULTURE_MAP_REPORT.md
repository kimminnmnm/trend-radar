# PHASE V4 Visual Culture Map

작성일: 2026-11-02

## 범위

Culture Map에 **VISUAL MODE** 보기를 추가했다. 기존 문화 관계 엔진·점수·저장 데이터는 바꾸지 않고, 시각 유사성을 별도 레이어로 얹는다.

| 기능 | 내용 |
|---|---|
| 보기 전환 | LIVE GRAPH에서 `CULTURE` / `VISUAL MODE` 선택. 기본은 CULTURE(기존 화면 그대로) |
| 노드 썸네일 | VISUAL MODE에서 노드에 실제 수집 이미지 1장(Visual DNA 분석 이미지 우선) + 관찰 팔레트 색. 원본 URL 그대로, `no-referrer`, 실패 시 대체 그래픽 |
| 시각 유사 연결 | 분홍 점선. 두 트렌드 모두 Visual DNA가 있을 때만 계산. 문화 관계는 "겹쳐 보기"를 켤 때만 흐리게 함께 표시 |
| 이미지 비교 | 시각 유사 연결 패널: 양쪽 실제 이미지 나란히, 팔레트 비교(가까운 색 ΔE), 공통 관찰 특징, 한쪽에서만 관찰된 특징, 문화 관계 유무. 문화 관계 패널에도 양쪽 이미지 비교를 추가 |
| 노드 패널 | 실제 이미지 최대 4장(원본 링크), 팔레트, Visual DNA 분석 시각, 시각 유사 연결 목록. Visual DNA가 없으면 안내만 하고 자동 분석하지 않음 |

## 시각 유사 점수 (`lib/visual-map.ts`)

```
score = 0.6 × palette + 0.4 × features   (한쪽이 없으면 있는 항목만으로 가중 평균)
palette  양쪽 팔레트의 각 색이 상대 팔레트의 가장 가까운 색과 얼마나 가까운지 평균, closeness = max(0, 1 − ΔE76/45)
features 같은 시각 차원 안 관찰 특징 이름의 글자 2-gram 유사도 ≥ 0.25를 1:1로 짝지은 Dice 계수
표시 조건 score ≥ 0.40 이고 가까운 색(ΔE ≤ 20) 또는 공통 관찰 특징이 1개 이상
```

- 입력: 저장된 Visual DNA의 `palette`(이미지 인용 있는 색)와 `basis: observed` + 이미지 인용이 있는 특징만. 해석(inferred, Visual Mood)은 점수에 넣지 않는다.
- 기준값 0.40은 **실측 분포로 보정하지 않았다**. 실측 Visual DNA가 1건뿐이기 때문이다. 화면에도 그렇게 표시한다.
- 화면 문구: 시각적으로 닮았다는 뜻이며 문화적 관계·확산·인과를 뜻하지 않는다.

## 데이터·비용

- 새 테이블·마이그레이션 없음. Visual DNA는 기존 `trend_visual_dna`(0006)/브라우저 분석 사본을 읽기만 한다.
- 새 API 호출 없음(유료 0회). 테스트에서 analyze/dna/collision/lab/studio/visual-dna/images 요청 0건을 확인했다.
- 이미지는 서버에 복제하지 않는다. AI 생성 이미지는 이 화면에 섞지 않는다(REAL REFERENCE만).

## 한계

- 실측 Visual DNA는 헤이세이 레트로 1건뿐이라 **실제 두 트렌드 간 시각 유사 연결은 아직 확인하지 못했다**. 두 번째 Visual DNA는 테스트 안에서만 만든 "테스트 전용 시각 사본"으로 검증했다. 실제 확인에는 다른 트렌드 하나 이상을 TREND DNA 화면에서 Visual DNA 분석(유료, 사용자 실행)해야 한다.
- 특징 비교는 이름 글자 유사도라 동의어("파스텔"과 "연한 색")는 놓친다. 임베딩 비교는 비용 때문에 넣지 않았다.
- 노드 배치는 기존 원형 배치를 그대로 쓴다. 시각 유사도로 배치하지 않는다.
